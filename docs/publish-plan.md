# 独立GitHub发布规划

日期：2026-10-08。用户授权将现有整合插件单独公开发布，并让琪琪市场刷新后能够发现。

## 方案比较与决定

| 方案 | 安装与更新 | 代价 |
|---|---|---|
| 公开仓库源码快照 | 市场可以发现并安装固定提交 | 含开发材料，版本附件不明确 |
| 公开仓库及版本ZIP（采用） | 市场可以发现，选择v0.2.0安装和检查更新 | 需要验证ZIP、元数据和发布附件 |
| 仅提供手动安装ZIP | 用户复制目录后重启 | 无法满足市场发现需求 |

仓库使用bailigebai/graydither.koplugin，保持现有独立目录。琪琪市场v0.1.3读取该账号公开仓库列表，按.koplugin后缀筛选，因此无需更改市场程序或维护白名单。v0.2.0明确标注“设备测试版”；真机结论不因发布而改变。

## 本阶段范围与验收

1. 补齐README安装和开发说明、_meta.lua静态名称、开发依赖版本；整理许可与公共文档路径。灰度和刷新行为不变。
2. 完整测试、重新打包、解压包测试和新上下文只读审查；检查公开文件不含凭据或用户本机路径。
3. 创建公开独立仓库、main分支与v0.2.0 Release，上传插件ZIP、验收CBZ和hash清单。
4. 从远端重新读取仓库目录和Release，下载已上传ZIP比较hash，并用琪琪市场真实目录/归档检查验证发现与可识别安装目录。

不修改其他插件源码、不安装到真实设备、不发布原来没有LICENSE的桌面补丁。设备上最终验收：琪琪市场刷新缓存，搜索graydither，选择v0.2.0安装，重启后使用两个功能菜单。
