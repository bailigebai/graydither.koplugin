# GrayDither v0.3.0 · 内置漫画阅读器灰度与全刷

MangaWeb和WebDAV漫画的内置图片阅读器现在能使用同一份灰度抖动与墨水屏刷新核心。两个阅读器在各自设置中分别开启或关闭灰度和自动全刷，**首次默认均关闭**，互不影响，也不继承普通书籍的全局开关。

请一起更新三个插件：

- GrayDither 0.3.0：本Release的graydither-0.3.0.zip。
- [MangaWeb 0.8.84](https://github.com/bailigebai/mangaweb.koplugin/releases/tag/v0.8.84)。
- [WebDAV漫画 0.4.16](https://github.com/bailigebai/webdavmanga.koplugin/releases/tag/v0.4.16)。

完全退出KOReader，备份旧插件与设置，把三个.koplugin文件夹复制至自己的plugins目录并保留缓存/用户数据，再启用插件并完全重启。MangaWeb原有授权流程保留。详见[三插件安装说明](https://github.com/bailigebai/graydither.koplugin/blob/main/docs/external-readers-install.md)。

MangaWeb在“设置 → 灰度与全刷”打开；WebDAV漫画点击正文中间，在阅读菜单打开“灰度抖动与墨水屏刷新”。灰度只处理最终缩放后的正文图像，保留原图和缓存。首次与同屏重绘不计数，成功显示不同正文屏后累计；短暂下载暂停并保留累计，设置/休眠/关闭取消旧任务。WebDAV接管期间临时停止原每页全刷与动画，关闭新功能后恢复原策略。

自动间隔1～50次，默认5。默认原生全刷，可选黑白辅助，各阶段保持0.10～1.00秒；立即全刷先返回正文。两项功能可独立使用。缺少、禁用或共享服务失败时，来源阅读器沿用原路径。

软件检查：GrayDither106项、MangaWeb40组、WebDAV193组及687项真实正文联测通过，包含最终解包产品检查和独立审查。重要边界包括透明背景、夜间、半像素居中、旧配置升级、分格平移缩放、长条跨图加载及关闭/休眠撤销。

这是设备测试版，尚未验证Kindle、Android、鸿蒙实机的画质、触控、波形、残影和性能。“256阶”表示256个输入亮度经软件抖动输出16级，不改变屏幕硬件。鸿蒙设备需先能运行KOReader；本项目不提供HarmonyOS NEXT原生HAP。

琪琪市场：联网“刷新缓存”，查找graydither并选择graydither-0.3.0.zip。graydither-test.cbz为测试漫画，sample-preview.png为预览，均不是插件安装包。旧公开版本保留。
