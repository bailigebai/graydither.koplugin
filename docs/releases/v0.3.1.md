# GrayDither v0.3.1 · 刷新数字框与设置稳定性修复

设备测试版，安装包为 `graydither-0.3.1.zip`。WebDAV 漫画用户若还遇到书架 E003，请同时更新 WebDAV Manga 0.4.18，可下载其发布页的完整修复套装。

## 本次改动

- 自动刷新次数、黑白保持时长的原生数字框显示在当前设置上方，可以正常调整。
- 刷新次数1～50，默认5；保持时长0.10～1.00秒，默认0.30秒。使用原生加减、长按和默认值按钮，保留原参数。
- 共享设置管理所拥有的父子窗口，退出恢复正文状态；旧回调、窗口创建/显示/关闭失败、事件与设置保存异常有保护。
- 图片算法和各来源独立保存的开关保持原行为，默认关闭。

## 验收

完全退出 KOReader，将 `graydither.koplugin` 文件夹覆盖到 `koreader/plugins/`，保留 KOReader 设置，再重启确认0.3.1。在已接入来源的阅读设置打开灰度与全刷，将自动间隔改4，确认并重新进入应显示4；检查默认5、时长默认0.30，以及反复调整和返回阅读。

桌面119项测试和10个产品Lua编译、两个来源的接入验证见 `docs/settings-repair-verification.md`。尚未安装本包进行 Kindle 真机复测，触摸、刷新时序和所有其他退出仍待验收。
