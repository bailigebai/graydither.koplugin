# 漫画灰度与墨水屏刷新 0.3.0

KOReader独立插件，设备测试版。为MuPDF绘制的CBZ／CBR漫画提供Floyd–Steinberg空间抖动，把256个输入亮度映射为16个输出灰阶。可改善某些图片的渐变观感，不代表屏幕拥有原生256灰阶。

支持手动全刷、每1～50次页面变化自动全刷，以及可选黑白辅助刷新。灰度和刷新分别开关；EPUB／PDF等原生文档可使用刷新功能。

0.3.0新增MangaWeb与WebDAV漫画内置阅读器接入。两个阅读器各自保存“灰度抖动”和“自动全刷”开关，**默认都关闭**，互不影响，也不继承本插件的全局开关。图片在最终缩放后处理，算法和刷新流程由本插件统一提供。

项目：[bailigebai/graydither.koplugin](https://github.com/bailigebai/graydither.koplugin)。0.3.0设备测试版下载：[GitHub Release](https://github.com/bailigebai/graydither.koplugin/releases/tag/v0.3.0)。安装时选择graydither-0.3.0.zip；旧版下载保留在[Releases](https://github.com/bailigebai/graydither.koplugin/releases)。

## 已实现

- 默认关闭；全局默认开关。
- 单本书开启、关闭或跟随全局。
- 灰度BB8与彩色RGB32页面，保留RGB32 alpha。
- 在最终缩放后的页面区域处理，不改原图或阅读器页面缓存。
- 沿用阅读器gamma、旋转、夜间模式和刷新策略。
- 未支持的模式、格式、页面区域和处理异常显示原图。
- 只挂接当前文档实例，关闭书籍时清理，不覆盖后来安装的其他插件包装。
- 使用宿主全局／文档设置，不硬编码Android或Kindle数据路径。
- 自动全刷默认关闭；开启后默认每5次页面变化，关闭再开保留所选间隔。
- 原生全刷默认，黑白辅助可选；黑白两阶段分别保持0.10～1.00秒，默认各0.30秒。
- 同页更新不计数；快速翻页和手动连点不叠加刷新。关书、休眠和旋转取消待执行流程。

## 安装

1. 解压graydither-0.3.0.zip，得到graydither.koplugin文件夹。
2. 将整个文件夹放进当前KOReader数据目录的plugins文件夹，不要再多套一层目录。
3. 重启KOReader，打开CBZ／CBR漫画。
4. 在阅读菜单“工具 → 更多工具 → 漫画灰度抖动”中选择“本书：开启”。
5. 查看“状态与支持范围”。翻页后“本次成功处理次数”增加，说明进入了处理路径。

常见位置：

- Kindle：USB根目录koreader/plugins/；设备路径通常/mnt/us/koreader/plugins/。需要能运行KOReader的设备，越狱与宿主安装条件按具体型号／固件确认。
- Android：常见/sdcard/koreader/plugins/，以实际KOReader数据目录为准。
- 鸿蒙：宿主能正常运行且能访问数据目录时使用实际目录。APK兼容设备与HarmonyOS NEXT／5+原生环境不同；本轮没有验证兼容层，也不提供HAP。

如果菜单位置因宿主版本不同有所变化，可在工具菜单查找“漫画灰度抖动”。插件实际搜索目录可以从启动日志“Looking for plugins in directory:”确认。

从旧版升级时覆盖原graydither.koplugin目录，然后重启KOReader。如果设备已经安装2-eink-full-refresh.lua原补丁，退出KOReader后将它移出patches目录，再使用整合版，避免两个自动流程同时生效。桌面原文件不受本项目修改。

设置与KOReader一起保存：全局G_reader_settings和每本书DocSettings分别使用graydither_enabled。插件不创建文件名映射或自己的路径配置。

## 两个漫画插件的内置阅读器

接入版本：GrayDither 0.3.0、[MangaWeb](https://github.com/bailigebai/mangaweb.koplugin) 0.8.84、[WebDAV漫画](https://github.com/bailigebai/webdavmanga.koplugin) 0.4.16。同时安装三个版本的插件文件夹后，完全退出并重启KOReader，在插件管理里启用它们。只更新GrayDither不能为旧版内置阅读器增加设置入口。

1. 通过漫画插件原来的入口打开漫画，在它自己的阅读设置中打开“灰度与全刷”。
2. “启用漫画灰度抖动”和“启用自动全刷”可以分别开启／关闭；首次进入均未勾选。
3. 在“墨水屏刷新”里选择间隔、原生／黑白辅助及保持时间。点击“立即全刷”会先返回正文，自动开关关闭时也可手动使用。
4. 另一个漫画插件的开关和参数保持独立。退出重开后保留各自选择。

仅正文图片经过灰度处理，工具栏、设置、加载提示与封面预加载不处理、不计数。按成功显示的不同阅读屏累计：包括源插件已实现的分片、平移、长条定位和分格视图；没有增加或修复源插件原有显示模式。首次和同屏重复重绘不计。短暂下载暂停但保留已成功显示的计数；设置、休眠和旋转重新建立基准。

WebDAV自动全刷由本插件接管时，临时停用原每页全刷和翻页动画以避免叠加；原来的设置值保留，关闭本功能或服务不可用时恢复原策略。缺少／禁用GrayDither仍能按原方式阅读，设置入口会提示服务不可用。原生书籍设置与两个漫画来源设置分开保存。

## 墨水屏刷新使用方法

在阅读菜单“工具 → 更多工具 → 墨水屏刷新”中操作：

1. “立即全刷”：按当前方式刷新一次，自动开关关闭时也能使用。
2. “启用自动全刷”：勾选后按所选间隔触发，默认未勾选。
3. “自动间隔”：1～50次页面变化。初始页不计，同页重复更新不计，跳到另一页算一次变化。EPUB滚动按书籍页码变化计数，不按滑动次数。
4. “刷新方式”：先试默认“原生全刷”；如果效果不足，可对照“黑白辅助”。辅助方式会先显示两种纯色，再恢复阅读画面。
5. “黑白各保持”：仅辅助方式有效，两阶段分别0.10～1.00秒，默认各0.30秒；不包含设备驱动自身耗时。
6. “刷新状态与说明”：查看方式、间隔、完成请求次数和暂缓／失败状态。

原生方式请求KOReader的full刷新，具体波形由设备适配执行。黑白辅助是纯色覆盖与刷新请求，不能保证所有厂商驱动会因此切换高质量波形或彻底消除残影。夜间模式可能交换屏幕实际显示的黑白顺序。

滚动中的请求会被宿主降为快速刷新，因此本插件暂缓触发；到期后只保留一个可取消的任务，每0.25秒检查滚动是否结束，松手后即可请求全刷，无需继续翻页。菜单／对话框遮挡时则保留计数，后续页面更新再尝试。手动刷新完成后清零自动计数；关书、休眠、旋转或改设置时取消未完成流程。普通触摸和按键在黑白覆盖期间被拦截。

刷新设置全局保存为graydither_refresh_enabled、interval、mode、hold四个命名键（后三项也含graydither_refresh_前缀）。不改宿主full_refresh_count，也不自动读取／迁移原补丁的eink_refresh_*设置。

## 支持条件

原生书籍灰度只处理MuPDF固定页面的CBZ／CBR。要求：

- 关闭重排（text_wrap=0）。
- 页面优化关闭（page_opt为0或未设置）。
- 自动纠偏为0。
- 白色阈值为默认255。
- 灰度页面BB8；彩色页面color_bb_type为RGB32，并核对真实缓存tile格式。
- 页面区域为整数，不使用scaled_rect；支持完整落在目标范围内的非负小数居中位置。
- 请求区域宽高不超过8192，像素总数不超过8 Mi。
- 目标屏幕缓冲为BB8或RGB32。

其他情况沿用原绘制，并在状态中说明原因。小数源区域、负小数目的坐标或需要目标边界裁剪的小数坐标会跳过。正常居中的半像素目的坐标按宿主规则向下取整，不改变绘制尺寸。EPUB、普通PDF、DJVU及宿主图片浏览器不接入原生灰度；漫画插件能成功解码并显示的正文图片可通过新的会话接口处理，不受原生CBZ／CBR文件后缀限制。

原生文档路径暂时关闭该文档当前调用中的软件抖动，结束后恢复原值。内置漫画路径仅将正文实例的目标绘制路由到私有缓冲，避免先软件抖动再FS，不改全局屏幕标记。硬件抖动与波形继续由宿主控制。额外全刷只由独立刷新功能请求。最终硬件处理效果需要真机对照，不承诺显示链路只处理一次。

## 最简单的验收

配套graydither-test.cbz包含3页：

1. 上部连续灰阶渐变、中部16阶色块、灰51区域和底部黑白细线。
2. 径向渐变及细节网格。
3. 0、51、52、128、200、255纯灰区域，检查亮度漂移。

先选“本书：关闭”，记住画面；再选“本书：开启”，查看渐变、网点和文字边缘。连续翻页／返回或刷新同页20次，亮度不应持续下降。再测试：

- 全局关闭时本书开启，成功处理计数应增加。
- 全局开启时本书关闭，成功处理计数不再增加。
- 横竖屏、夜间模式、菜单打开关闭，检查方向与显示。
- 调整宿主硬件抖动和全刷选项做对照，记录速度与残影。

某些设备原生抖动已经足够好，开启本插件未必改善每张图片。选择效果好的配置即可。

全刷验收：先关闭自动，点击“立即全刷”，确认最终仍是阅读画面。再将间隔设为3并启用自动：打开书的初始页不计数，第3次不同页码变化请求一次全刷；使用3页验收漫画时可以反向翻页完成第三次变化。分别对照原生、黑白辅助和0.10／0.30秒保持；在排队、第一和第二纯色阶段尝试关书、休眠、横竖屏，返回后不应残留纯色覆盖层。PDF／EPUB也应能单独刷新，无需开启漫画灰度。

## 关闭与卸载

选择“本书：关闭”即可立即回到原绘制。全局关闭只影响跟随全局的书，已强制开启的书需单独改为关闭／跟随。

关闭全刷：取消“启用自动全刷”；它不影响灰度开关，手动全刷仍可使用。进行中的流程会取消并移除覆盖层。

卸载：退出KOReader后移走plugins/graydither.koplugin文件夹，再启动。宿主中的命名偏好会保留但不再生效，无需删除阅读器设置。

## 开发

在仓库根目录使用Python 3.11及Lupa 2.8的LuaJIT21运行测试；这些是开发依赖，不进入设备安装包。在已有Python虚拟环境中准备依赖：

```text
python -m pip install -r requirements-dev.txt
python scripts/run_tests.py
```

测试fixture为固定版本源码，hash记录在tests/fixtures/provenance.json；fixture不进入设备安装包。打包：

```text
python scripts/package.py
```

产物写到dist，脚本仅写本项目产物。设计、实现计划和执行证据位于docs。
